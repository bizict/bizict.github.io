# 허브(Hub) 정의

- 이 프로젝트에서 "허브"는 **Notion**을 의미한다.
- 사용자가 "허브에 저장/반영/기록해줘"라고 하면, Notion MCP 서버를 통해 사용자의 Notion 워크스페이스에 반영한다.
- Notion 연동은 공식 호스팅 MCP 서버(`https://mcp.notion.com/mcp`, Streamable HTTP, OAuth 인증)를 사용한다.
- 기획안·설계 결정·조사 결과 등 "문서로 남길 가치가 있는 산출물"은 기본적으로 허브(Notion)에 저장하는 것을 우선 고려한다.
